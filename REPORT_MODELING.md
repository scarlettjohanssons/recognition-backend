# Звіт: Математична модель системи розпізнавання аудіосигналів

## 1. Обґрунтування використання методу моделювання

Об'єктом дослідження є процес автоматичної класифікації звуків навколишнього середовища (15 класів: Bike, Cat, Crow, Crowd, Dog, Elephant, Horse, Lion, Office, Parrot, Rainfall, Sparrow, Traffic, Train, Wind). Система працює у двох режимах: single-label (один клас на запис) та multi-label (кілька класів одночасно).

Реальний аудіосигнал є стохастичним процесом, який залежить від характеристик джерела звуку, акустичного середовища, параметрів записуючого обладнання та зовнішніх завад. Аналітичний опис таких процесів є надзвичайно складним, тому обрано метод комп'ютерного моделювання.

**Моделювання дозволяє:**
- формалізувати процес обробки аудіосигналу як послідовність математичних перетворень;
- експериментально варіювати параметри (частота дискретизації, кількість мел-фільтрів, архітектура мережі) та оцінювати їх вплив на якість класифікації;
- оптимізувати модель до етапу впровадження;
- кількісно оцінити якість за метриками Accuracy, Precision, Recall, F1-score.

**Конвеєр обробки** складається з таких етапів:

```
Аудіо (.wav) → Дискретизація (22050 Гц) → Мел-спектрограма (128 фільтрів) → PNG (224×224) → CNN → Класифікація
```

**Ключова формула — перетворення частоти в мел-шкалу:**

```
mel(f) = 2595 * log10(1 + f / 700)
```

Мел-спектрограма обчислюється як добуток потужнісного спектру на банк трикутних мел-фільтрів, після чого переводиться в децибели та нормалізується.

**Класифікація** виконується згортковою нейронною мережею (CNN). Для single-label задачі вихідний шар використовує функцію softmax (сума ймовірностей = 1), для multi-label — sigmoid (незалежна ймовірність для кожного класу, поріг τ = 0.3).

## 2. Обґрунтування вибору математичного пакету

Для реалізації математичної моделі обрано середовище **Python 3.x** з екосистемою наукових бібліотек.

**Причини вибору:**

| Критерій | Рішення |
|----------|---------|
| Обробка аудіо | **Librosa 0.10.2** — STFT, мел-спектрограми, ресемплінг |
| Нейронні мережі | **TensorFlow / Keras** — побудова та навчання CNN |
| Чисельні обчислення | **NumPy 2.1.3**, **SciPy 1.15.1** |
| Оцінка якості | **Scikit-learn 1.6.1** — Precision, Recall, F1-score |
| Візуалізація | **Matplotlib** — спектрограми, графіки |
| Розгортання | **FastAPI 0.115.7** — REST API |

**Альтернативи та причини відхилення:**

| Альтернатива | Причина відхилення |
|--------------|--------------------|
| MATLAB | Комерційна ліцензія, слабка підтримка сучасних DL-архітектур |
| R | Обмежена екосистема для глибинного навчання |
| PyTorch | Рівноцінна альтернатива, але Keras простіший для прототипування |

## 3. Основні характеристики обраного математичного пакету

### Librosa 0.10.2
Спеціалізована бібліотека для аналізу аудіосигналів. Реалізує завантаження аудіо з ресемплінгом, обчислення STFT, мел-спектрограм, MFCC, спектрального центроїда. У проекті використовується для перетворення .wav файлів у мел-спектрограми з параметрами: частота дискретизації 22050 Гц, 128 мел-фільтрів.

### TensorFlow / Keras
Фреймворк для побудови та навчання глибинних нейронних мереж з підтримкою GPU-прискорення. У проекті реалізовано CNN з трьома згортковими блоками (Conv2D + BatchNormalization + MaxPooling2D), GlobalAveragePooling2D та повнозв'язними шарами. Підтримує автоматичне диференціювання, оптимізатор Adam, функції втрат categorical/binary crossentropy.

### NumPy 2.1.3
Бібліотека для ефективних чисельних обчислень з багатовимірними масивами. У проекті використовується для нормалізації сигналів, обрізання значень спектрограм (`np.clip`), накладання аудіосигналів (`np.sum`), нормалізації зображень (поділ на 255).

### Scikit-learn 1.6.1
Інструмент оцінки якості моделей. У проекті використовується `classification_report` для обчислення метрик Precision, Recall, F1-score, а також `MultiLabelBinarizer` для кодування multi-label міток.

### FastAPI 0.115.7
Асинхронний веб-фреймворк для розгортання моделі як REST API. Забезпечує два endpoints для класифікації: single-label (`POST /predict/predict`) та multi-label (`POST /multiple_predict/predict`), автоматичну генерацію Swagger-документації та валідацію вхідних даних.

| TensorFlow/Keras | latest | CNN, навчання, інференс |
| NumPy | 2.1.3 | Чисельні обчислення |

## Висновок

Метод комп'ютерного моделювання дозволив формалізувати процес класифікації аудіосигналів, дослідити вплив параметрів обробки на якість розпізнавання та оптимізувати архітектуру CNN-моделі. Обране середовище Python із бібліотеками Librosa, TensorFlow/Keras, NumPy, Scikit-learn та FastAPI забезпечує повний цикл від математичного моделювання до практичного розгортання системи.
